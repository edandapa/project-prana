# project-prana: The Agent Foundry 🤖

Welcome to **Project Prana**, a central hub for autonomous AI agents. This project explores the intersection of **Retrieval-Augmented Generation (RAG)** and the **Model Context Protocol (MCP)** to build systems that don't just "chat," but take action.

## 🏗️ The Agent Directory

### 💼 Customer Success & CRM Ops
* **[Executive Change Agent](./executive-change-agent)**: Monitors LinkedIn for stakeholder transitions, updates HubSpot CRM, and retrieves churn-mitigation strategies via Local RAG.
* **[CS HubSpot Healthscore](./cs-hubspot-healthscore)**: Automates account health monitoring and data hygiene within HubSpot.

### 📈 Career & Professional Growth
* **[Job Pulse Agent](./job-pulse-agent)**: An automated search engine for targeted roles across major job boards (Greenhouse, Lever, etc.).
* **[Career Site Monitor](./career-site-monitor)**: Real-time tracking of specific company career pages for high-priority openings.

### 🛠️ Personal Utility & Research
* **[Flight Assistant](./flight-assistant)**: A travel agent utilizing the Amadeus API and ChromaDB to manage bookings based on personal preferences.
* **[AI News Agent](./ai-news-agent)**: Scrapes and synthesizes the latest developments in Agentic AI and LLM research.

### 📈 Fintech & Risk Management

MNQ Trading Assistant: A decision support system for Micro Nasdaq futures using the ICC (Indication, Correction, Continuation) framework. It monitors market structure shifts and identifies high-probability entries while enforcing LUCID $25K evaluation rules, including the 40% Consistency Cap.

## 🧘‍♂️ About Project Prana
"Prana" represents the vital life force. In this context, the project is about breathing "life" into static data and playbooks by turning them into active, agentic workflows. Every agent in this foundry is designed to reduce manual toil and allow for more strategic, high-level decision-making.
